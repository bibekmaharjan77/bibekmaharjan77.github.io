Research

Research Projects

Learning-augmented distributed directories

When a node writes to a shared object, ownership moves to that node. A later reader needs to find the current owner to get a copy. We asked whether predicting which nodes will request the object can reduce the distance that directory messages travel, even when some predictions are wrong.

Our IEEE NCA 2025 paper studied the case where all predicted requesters are known at the outset, but their request times are unknown. In our SSS 2026 paper, Online Learning-Augmented Distributed Directories, we studied the case where predictions themselves arrive over time.

We studied two protocols: The first connects the initially predicted nodes and the owner with a Steiner tree, attaches the remaining nodes by shortest paths, and keeps that tree fixed. The second organizes nodes into clusters. An initially predicted node can become a leader when a request path visits its cluster. This was an incremental but a novel approach we used in our work.

We evaluated both protocols on random, small-world, Internet-like, and grid networks. We measured stretch by comparing the total distance along the overlay with the total shortest-path distance in the original network for the same sequence of holders, starting with the owner. This let us examine how much extra distance the protocols incurred as prediction error varied.

Online routing with multiple repairpersons

We’re studying the online traveling repairperson problem on a line. A request arrives at a location, and the algorithm learns about it only when it is released. With several repairpersons, the algorithm must decide who serves each request and in what order. We’re analyzing how to make those decisions using only the requests known so far.

Big Data Analytics Course project in distributed subgraph matching

For our Big Data Analytics course, we built a Hadoop MapReduce pipeline to find occurrences of a query graph inside a larger graph. Before verifying a match, the pipeline compares signatures that summarize the neighborhoods around candidate vertices. This rules out structurally incompatible candidates before the more expensive verification step.
